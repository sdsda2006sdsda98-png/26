# Фото для сайта

Клади фотографии прямо в эту папку и называй файлы так:

- `photo1.jpg` - главная общая фотография, самый теплый кадр.
- `photo2.jpg` - фото для карточки "тепло".
- `photo3.jpg` - фото с улыбкой.
- `photo4.jpg` - маленькая история или случайный милый момент.
- `photo5.jpg` - кадр, который хочется запомнить.
- `photo6.jpg` - простое совместное фото.

Можно использовать `.jpg`, `.jpeg` или `.png`, но в `src/App.jsx` сейчас прописаны именно `.jpg`.
Если файл будет называться иначе, поменяй путь в массиве `photoMemories` в `src/App.jsx`.

Рекомендуемый размер: вертикальные фото примерно 1200x1500 или больше. Сайт сам обрежет их под карточки.
